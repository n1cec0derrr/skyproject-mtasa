# Sky DLC Studio

Программа с окном для сборки зашифрованных пакетов `.skydlc` (формат v3, AES-256-GCM) для клиента Sky Project.
На клиенте не нужно держать `.img`: игра получает их из пакетов через `Client/core/DLC`.

## Как устроен контент

Папка контента повторяет папку игры (ту, где лежит `gta_sa.exe`):

```
D:\SkyDLCContent\
    models\gta3.img\          папка с именем *.img — это IMG-архив
        infernus.dff
        infernus.txd
        ...
    data\Paths\skyproject_vehs.img\
    data\gta.dat              все остальные файлы попадают в игру как есть
    data\maps\...\*.ide, *.ipl
```

- Галочка **«Один общий файл»** (по умолчанию включена): все архивы и все файлы данных лежат в одном
  `sky_project.skydlc`. Каждый IMG (VER2) собирается на лету и сразу шифруется, временного `.img` на диске нет.
  Новый контент потом добавляется патчем `zz_patch.skydlc`, общий файл при этом не трогается.
- Без галочки: каждая папка `*.img` становится своим пакетом (`models\gta3.img` → `models_gta3.skydlc`),
  а файлы вне `*.img` идут в `files.skydlc`.
- При смене раскладки собирается всё, а пакеты старой раскладки удаляются после того, как новые записаны и проверены.
  Если старый пакет чем-то занят, он помечается «лишний пакет» и удаляется при следующей сборке.
- Пути внутри пакетов считаются от папки `gta_sa.exe` (`models/gta3.img`, `data/gta.dat`).
- Куски карты: `<папка игры>\data\maps\nulllocal\sky\Ripki\ripki.IPL` попадает в пакет
  как `data/maps/nulllocal/sky/Ripki/ripki.IPL`. Игра открывает их по строкам `IDE`/`IPL` из `gta.dat`
  (`IPL DATA\MAPS\nulllocal\sky\Ripki\ripki.IPL`). Регистр букв клиент не различает.
- После каждой сборки в журнал пишется проверка ссылок из `gta.dat` и `default.dat`: сколько файлов
  найдено в пакетах, сколько игра возьмёт с диска и каких нет нигде (с такими игра упадёт при загрузке).
- Пакеты кладутся в папку `dlc` рядом с `Sky Project.exe` (клиент ищет её как `CalcMTASAPath("dlc")`).
  Для клиента, собранного из этого репозитория: папка игры `Bin\runtime\GTA San Andreas`, пакеты в `Bin\dlc`.
  Студия подставляет эти пути сама, если собрана внутри репозитория.
- Служебный файл `.skystudio\state.txt` в папке контента запоминает, из чего собран каждый пакет.
  Если его удалить, следующая сборка пересоберёт всё.

## Кнопки

| Кнопка | Что делает |
|---|---|
| **Импорт из игры** | Один раз раскладывает все `.img` из папки игры по папкам контента. Копирует ещё всю папку `data\maps` с подпапками (куски карты), `data\gta.dat`, `default.dat` и остальные `*.ide`/`*.ipl` из `data`. Уже разложенные архивы и существующие файлы не трогает, игру не меняет. Дубликаты имён внутри IMG пропускаются: игра всё равно берёт первый. |
| **Собрать изменённые** | Пересобирает целиком только те архивы, в которых что-то поменялось. Патч при этом убирается: его содержимое уходит в архивы. |
| **Собрать патч** | Основной пакет не трогает. Новые и изменённые модели кладёт в маленький `zz_patch.skydlc` (внутри `models\sky_patch.img`), в `data\gta.dat` первой IMG-строкой добавляется `IMG models\sky_patch.img`. В раскладке «один общий файл» в патч идут ещё новые и изменённые файлы данных (`gta.dat`, `.ide`, `.ipl`, куски карты из `data\maps`): `zz_patch` грузится после `sky_project` и перекрывает их. |
| **Пересобрать всё** | Пересобирает все пакеты, даже актуальные. Патч убирается. |
| **Проверить пакеты** | Расшифровывает каждый `.skydlc` из папки dlc текущим ключом. |
| **Обновить** | Перечитывает папку контента и показывает, что требует сборки. |

После каждой сборки пакет пишется во временный файл, расшифровывается обратно и побайтно
сравнивается с исходниками. Только после этого он заменяет старый пакет. Если проверка не прошла
или сборку отменили, старый пакет остаётся на месте.

### Когда патч, а когда полная сборка

Игра берёт модель из **первого** архива, в котором она нашлась. Архивы из строк `IMG` в `gta.dat`
читаются после `gta3.img` и `gta_int.img`. Поэтому:

- **новые** модели (новые имена) всегда можно класть в патч;
- **замену** моделей из архивов, перечисленных в `gta.dat` (например, `data\Paths\skyproject_vehs.img`),
  тоже можно класть в патч: строка патча стоит раньше них;
- замена моделей в `gta3.img`, `gta_int.img`, `player.img`, `anim.img` и других архивах, которые движок
  открывает сам, через патч не сработает. В таком случае студия пересобирает этот архив целиком.
- Удалённые из папки файлы пропадут из игры только после полной сборки этого архива.

Проверьте один раз в игре, что замена модели из `skyproject_vehs.img` через патч действительно применяется.

## Ключ

Используется тот же `Client\core\DLC\SkyDLCKey.local.h`, с которым собран клиент.
Отпечаток ключа показан справа от поля. Он совпадает с `SkyDLCPacker fingerprint`.
Файл ключа никому не отдавать и в git не добавлять.

## Сборка exe

Нужна Visual Studio 2022 с C++. Запустите `build.bat`, получится `SkyDLCStudio.exe`
(x64, CRT вшит, ставить ничего не надо). Настройки окна хранятся в `SkyDLCStudio.ini` рядом с exe.
